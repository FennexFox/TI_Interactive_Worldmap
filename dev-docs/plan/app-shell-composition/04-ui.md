# Phase 04: Extract search and nation overlay controllers

## Goal

- Move UI-local search/dropdown and nation-panel DOM ownership behind context-fed controllers while keeping semantic app state in the runtime.

## Scope

- Search controller owns catalog filtering, open/highlight/choice state, dropdown rendering, search input events, and region visibility application through callbacks.
- Nation-overlay controller owns panel HTML/model presentation, project options, claim pill, claim-selection events, and region-selection events.
- Controllers provide `setContext`, `render`, `clear`, and `destroy`.

## Non-goals

- No search matching semantic change, catalog/schema change, panel redesign, selector/class/dataset change, claim-model change, or semantic state storage in controllers.
- No direct `appState` import.

## Affected files

- `src/app.js`
- `src/ui/search-controller.js`
- `src/ui/nation-overlay-controller.js`
- existing `src/ui/controls.js` and `src/ui/nation-info-panel.js` only for reusable rendering helpers/contracts
- focused `tests/unit/ui-controllers.test.js`
- relevant `tests/e2e/{search,overlays,language}.spec.js`
- derived `docs/assets/**` only through build
- this phase file

## Implementation steps

1. Separate semantic callbacks from UI-local dropdown/panel state.
2. Create the search controller and preserve catalog rebuild, visibility, keyboard/mouse, and selection behavior.
3. Create the nation-overlay controller and preserve HTML, claim pill/project option ordering, and delegated event behavior.
4. Feed current scenario/translation/model callbacks through `setContext`.
5. Replace `app.js` UI-local implementation, add lifecycle/context unit tests, and verify language/scenario reset behavior.
6. Run validation, record evidence, gate, and commit.

## Acceptance criteria

- Search and nation UI-local state/HTML/event ownership is outside `app.js`.
- Controllers expose the four required lifecycle methods and release listeners on destroy.
- Controllers do not retain semantic scenario/selection/claim state and do not import `appState`.
- Search aliases/tags/names/projects/regions, dropdown keyboard/mouse behavior, nation panel, project options, claim pills, language refresh, and selection callbacks remain compatible.

## Rollback risks

- Dropdown highlight/open state may leak across scenario/language contexts.
- Delegated panel listeners may duplicate after render.
- Escaping/localization or project ordering can change during HTML movement.
