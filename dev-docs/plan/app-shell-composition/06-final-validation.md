# Phase 06: Rebuild, compare, audit, and prepare PR

## Goal

- Prove the refactor preserves behavior/performance/contracts, commit only intended derived output, refresh structural navigation once, and complete Final/Commit Audit.

## Scope

- Run final lint/build/unit/verifier/full E2E gates.
- Regenerate checked-in Pages output from source without changing generated data.
- Repeat the exact phase-1 performance matrix five times and compare medians/counters/nodes.
- Refresh Graphify once and cross-check inferred relationships against actual source.
- Audit final diff, generated policy, phase evidence, commits, public APIs, module boundaries, and completion classification.
- Prepare a PR-ready summary; create the PR only if the connected/push workflow is authorized and available.

## Non-goals

- No new feature, opportunistic cleanup, data regeneration, Unity extraction, or behavior/performance redesign.
- No manual generated-output review or edit.

## Affected files

- `docs/assets/**` generated by `npm run build`
- `graphify-out/**` refreshed once
- `dev-docs/plan/app-shell-composition/**`
- `dev-docs/plan/README.md`

## Implementation steps

1. Run source lint/unit verification and full Playwright suite.
2. Run `npm run build`, verify only expected Pages assets changed, and run generated checks.
3. Run the same eight-scenario/five-repeat measurement to `.chatgpt/tool-tests/app-shell-composition-after`.
4. Compare per-scenario medians, nodes, replacements, and cache builds; isolate/repeat any ≥10% timing regression.
5. Refresh Graphify once, then confirm the reported runtime/controller/import relationships in source.
6. Update every phase outcome and the master Final Audit checklist.
7. Review final diff without line-reviewing generated artifacts; inspect commit sequence and scope.
8. Commit final derived/evidence docs and prepare the PR summary.

## Acceptance criteria

- Lint, complete unit/Python/verifier, and full Playwright suites pass with at least the repository's current test count.
- `npm run build` changes only expected checked-in Pages assets and `data/generated/**` remains unchanged.
- Equivalent SVG node, DOM replacement, and cache-build counters do not increase.
- No reproducible hot-path median regresses by 10% or more; any noisy breach is isolated and documented.
- Graphify is refreshed once and its architectural claims are checked against source.
- Final Audit and Commit Audit pass; all phase commits are reviewable and unrelated work is absent.
