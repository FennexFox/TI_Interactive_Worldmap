# Phase 01: Verify and regenerate Broken Earth claim data

## Goal

- Establish the exact Broken Earth claim-chain delta and regenerate repository data
  from the current installed game templates.

## Scope

- Locate the base and Dark Skies scenario template directories.
- Compare Broken Earth claim relationships in source templates with scenario `1962`
  in the checked-in generated bundle using targeted parsing.
- Run the local-game rebuild while reusing checked-in region geometry.
- Review changed paths and summarize claim-chain changes by nation, project, region,
  and claim flags.
- Add scenario `1962` verification sentinels for both new hostile capital-chain edges
  and the corrected `Project_BSBE_SensingWeakness` nation requirement.

## Non-goals

- Browser application logic or visual redesign.
- Manual edits to `data/generated/**` or `docs/**`.
- Region outline extraction or geometry refresh.
- Changes unrelated to authoritative template-derived data.

## Affected files

- `data/generated/**` and `docs/**` generated by `tools/rebuild_pages.py`.
- `tools/verify_generated_outputs.py` for Broken Earth dataset sentinels.
- `dev-docs/plan/be-claim-chain-refresh/**` for phase evidence.

## Implementation steps

- Confirm source paths and the Broken Earth scenario overlay rules.
- Capture a semantic before/after summary of scenario `1962` claims.
- Run `./scripts/build-wsl.sh --from-game --skip-install`.
- Extend generated-data verification with exact Broken Earth chain assertions.
- Confirm the generated manifest bounds the modified artifacts.

## Acceptance criteria

- Generated scenario `1962` reflects the installed Broken Earth templates.
- The reported claim-chain delta is reproducible from source templates.
- No region geometry is refreshed.
- Verification rejects either missing chain edge, a non-hostile edge, a target that is
  no longer the current owner's capital, or a regression to the old `GRE` requirement.
- `npm run verify` passes after regeneration.

## Validation commands

- npm run verify

## Manual smoke tests

- Parse scenario `1962` and confirm each changed project/claim chain has the expected
  endpoints and metadata from the Dark Skies source rows.

## Rollback risks

- A stale or partially installed DLC could produce an incomplete catalog refresh.
- Rebuilding all supported scenarios may surface legitimate upstream changes outside
  Broken Earth; semantic review is required before commit.

## Progress

- Completed source discovery against the installed base game and Dark Skies templates.
- Rebuilt all supported scenario catalogs and Pages output without refreshing geometry.
- Compared `HEAD` and rebuilt scenario data with targeted JSON parsers.
- Added exact Broken Earth chain and project-requirement sentinels.
- `npm run verify` passed after regeneration and verifier changes.

## Decision log

- Region geometry will not be refreshed because the request concerns claim data only.
- The two new rows are treated as capital-chain edges, not merely row-count changes:
  PAK now reaches the AFG capital at Afghanistan and VEN reaches the FAM capital at
  Amazonia; both are projectless hostile claims.
- The current upstream BE catalog also corrects Sensing Weakness from `GRE` to `ZAB`
  and fixes the Republic of Rome article typo, so those generated changes are retained.
- The 2003 research catalog has only source size/hash changes and no semantic node or
  edge changes; it is retained as reproducible provenance from the all-scenario build.
- Ruff was unavailable in `.venv-wsl`; the required compile, unit, and generated-data
  checks still ran through `npm run verify`.

## Outcomes / Retrospective

- Broken Earth claim rows increased from 2,098 to 2,100, with both additions matched,
  hostile, projectless, and represented in nation claim totals.
- `2022`, `2026`, and `2070` are semantically unchanged after the rebuild.
- Verification now fails if either new capital-chain link disappears or if Sensing
  Weakness regresses to its stale Greece requirement.
